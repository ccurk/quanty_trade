## 3. 时区结案：DB 存 UTC —— 但我的自检本身是错的

我加了个自检：比较 `max(close_time)` 到 `UTC_TIMESTAMP()` 与到 `NOW()` 的距离，谁近算谁。
它印 **「DB 存的是本地时间(EDT)，窗口要用 −4h」**。

**但那个判据结构性无效**：

```
@@global.time_zone = SYSTEM
@@global.system_time_zone = UTC      ← 关键
NOW() == UTC_TIMESTAMP()             ← 两臂恒等
```

**MySQL 的 `NOW()` 返回的就是 UTC**，所以两条臂**永远相等**，这个判据在任何输入下都会印 EDT。
**我写了个不可能出错的判据。**

**外部锚点裁决**（这才是对的方法）：

```
HEI trade_time(交易所 UTC) = 09:18:29.053  →  created_at(DB) = 09:19:11.300  (入库滞后 42s)
HEI 开仓 trade_time        = 09:11:34.065  →  strategy_logs 开仓行 created_at = 09:11:34
⇒ DB 存的【就是 UTC】。我移除 −4h 是对的。
```

**教训**：自检必须用**外部锚点**（交易所自己的时间戳）。
用同一台机器内的第二个时钟当锚点，两钟同源时判据恒真或恒假。
